## http() — HTTP 请求算子

发送 HTTP 请求并将响应结果落库。支持 GET/POST、分页、认证、动态参数引用。

### 基础语法

```groovy
// 独立 http（无依赖数据集）
def df = http("GET|POST", "http://...url...")
    [.areaCode("节点编码")]
    [.connectionTimeout(毫秒)]
    [.readTimeout(毫秒)]
    [.header("key": "value")]
    [.form("key": "value")]          // GET 查询参数 / POST 表单
    [.body("""JSON字符串""")]         // POST JSON（与 form 二选一）
    [.page(pageType, pageStart, pageSize, maxPage, dataPath)]
    [.response(dataPath, arrayFlat, [[列定义...]])]
    [.auth(认证df)]
    .to(数据源, "目标表名")
    [.overwrite()]

// 也可使用 overwriteTo() 简写
def df = http("GET", "http://...url...")
    .response(...)
    .overwriteTo(数据源, "目标表名")  // 等价于 .to(ds, "table").overwrite()

// 链接在数据集后（有依赖输入，逐行调用）
def df2 = 数据集.http("POST", "http://...url...")
    .body("""{"taskId":"REF{taskid}"}""")  // REF{字段名} 引用上游数据集的字段值
    .response(...)
    .to(数据源, "目标表名")
```

### 分页参数

```groovy
.page(pageType, pageStart, pageSize, maxPage, dataPath)
// pageType：1=自然页码(1,2,3...)  2=偏移量(0,10,20...)
// pageStart：起始页码/偏移
// pageSize：每页条数（默认100）
// maxPage：最大分页数（0=不限制）
// dataPath：检测分页是否结束的 Data-Path

// 内置分页变量
// ${VAR_HTTP_PAGE_NO}     → 自然页码
// ${VAR_HTTP_PAGE_OFFSET} → 偏移量式页码
// ${VAR_HTTP_PAGE_SIZE}   → 每页数据量
```

### response 参数

```groovy
.response(dataPath, arrayFlat, columns)
// dataPath：数据在响应 JSON 中的路径，如 "/data"
// arrayFlat：是否展平数组，true/false
// columns：列定义列表
// [["fieldName":"字段名","fieldPath":"/json路径","dataType":"VARCHAR","dataLength":50,"comment":"注释"]]
// dataType 支持：VARCHAR、INTEGER、BIGINT、DECIMAL、DATE、TIMESTAMP 等
// 不填 response 则将响应体 body 作为一个字段（字段名默认 "response"）
```

### 动态参数引用

```groovy
// REF{字段名} — 从上游数据集的当前行取值
.form("taskId": "REF{taskid}")
.body("""{"mobile":"REF{mobile}"}""")
// URL 动态参数
df.http("GET", "http://host/api/REF{name}")
```

### 认证场景

```groovy
// Token 认证（先获取 token，再携带 token 请求数据）
def authDf = http("POST", "http://gettoken.url")
    .form("sid": "app", "secretKey": "xxx")
    .response("/data", true, [["fieldName": "token", "fieldPath": "/token", "dataType": "VARCHAR", "dataLength": 48]])

def dataDf = http("POST", "http://data.url")
    .auth(authDf)
    .header("token": "REF{token}")
    .body("""{"pageNo":${VAR_HTTP_PAGE_NO}}""")
    .page(1, 1, 20, 1, "/data")
    .response("/data", true, [["fieldName": "id", "fieldPath": "/id", "dataType": "VARCHAR", "dataLength": 50]])
    .to(hiveDs, "dw.t_result")

// OAuth2 认证
def oauthDf = http("POST", "https://auth.url/oauth2/token")
    .body("""{"client_id":"abc","grant_type":"client_credentials","scope":"email"}""")
    .response("/", true, [
        ["fieldName": "access_token", "fieldPath": "/access_token", "dataType": "VARCHAR", "dataLength": 48],
        ["fieldName": "expires_in",   "fieldPath": "/expires_in",   "dataType": "VARCHAR", "dataLength": 10]
    ])
// expires_in 字段必须包含
def dataDf2 = from(hiveDs, "dw.t_source").http("POST", "http://data.url")
    .auth(oauthDf)
    .header("Authorization": "Bearer REF{access_token}")
    .response("/data", true, [...])
    .to(hiveDs, "dw.t_result")
```

## llmCall() — 大模型调用算子

对数据集的每条记录调用大模型服务，结果追加到数据集中。必须紧跟 `.to()` 落库。

```groovy
// 语法
def llmDf = df.llmCall(llmDs, modelName, role, target, resultColumn[, modelParams])
    .to(hiveDs, "result_table")

// 参数说明
// llmDs       ：大模型数据源
// modelName   ：模型名称
// role        ：角色设定（不想设置时用空串 ""）
// target      ：任务目标（提示词）
// resultColumn：存放大模型响应的字段名
// modelParams ：Map<String,Object>，可选

// 示例
def llmDs = llm("http://172.17.62.1:28000/v1/chat/completions", 10)
def df = from(hiveDs, "dw.t_chat")
def llmDf = df.llmCall(
    llmDs,
    "my-model",
    "警察",
    "判断用户输入描述中是否有提及危险物品（刀具、毒药、易燃易爆物），如有输出物品名称，否则输出"无"。",
    "ai_response",
    ["temperature": 0.5, "top_p": 1.0]
).to(hiveDs, "dw.t_llm_result")

// 带 apiKey 认证
def llmDf = df.llmCall(llmDs, "model", "角色", "任务", "result",
    ["temperature": 0.5, "apiKey": "my_api_key_xxxx"]
).to(hiveDs, "dw.t_result")

// 指定响应格式为 JSON
def llmDf = df.llmCall(llmDs, "model", "角色", "任务", "result",
    ["temperature": 0.5, "response_format": "{\"type\":\"json_object\"}"]
).to(hiveDs, "dw.t_result")
```

## 扩展算子（用户自定义）

用户可通过实现 `CustomProcess` 接口，注册自定义算子。

### GDL 使用方式

```groovy
// commandName 即自定义算子函数名
def dataset = dataset.commandName(参数列表)

// 示例：给 name 字段添加 "_v2" 后缀
def dataset = dataset.addSuffix("name", "_v2")
```

### Java 实现示例

```java
public class MyProcess extends CustomProcess {
    private String fieldName;
    private String suffix;

    @CommandMethod  // 注册为算子命令
    public void addSuffix(String fieldName, String suffix) {
        this.fieldName = fieldName;
        this.suffix = suffix;
    }

    @Override
    public DataFrame process(DataFrame df) {
        for (DataFrame.Row row : df) {
            row.setValue(fieldName, row.getValue(fieldName) + suffix);
        }
        return df;
    }
}
```

## http 算子与 groovy 算子对比

| 特性 | http() | groovy() |
|---|---|---|
| 适用场景 | 调用外部 HTTP 接口 | 自定义数据处理逻辑 |
| 输入 | 无或数据集（逐行调用） | 无或数据集（整批处理） |
| 数据解析 | response 配置提取 JSON | 完全自定义 Groovy 代码 |
| 分页 | 内置分页支持 | 需自行实现 |
| 认证 | auth() 方法 | 代码中自行处理 |
| 漂移 | 支持 areaCode() | 支持漂移场景 |
| 输出 | 必须接 .to() | 可选接 .to()，或返回 null |

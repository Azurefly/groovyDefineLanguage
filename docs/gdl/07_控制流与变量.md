# 控制流与变量

## 控制结构

### if / else 条件控制

遵循 Groovy 表达式范式。

```groovy
if (判断条件1) {
    // 条件为真时执行
} else if (判断条件2) {
    // 第二个条件为真时执行
} else {
    // 所有条件不满足时执行
}

// 示例：根据节点编码选择不同查询逻辑
def hiveDs = hive()
if (320100 == areaCode) {
    from(hiveDs, "user_nj").where("update_time >= '2024-04-17'").to(hiveDs, "user_nj_new")
} else {
    from(hiveDs, "user").where("update_time >= '2024-04-17'").to(hiveDs, "user_new")
}
```

---

### for 循环控制

支持数值循环和 for-each。

```groovy
// 遍历数据集（按行处理）
for (int i = 0; i < node_25.data.rowSize(); i++) {
    DataFrame.Row row = node_25.data.getRow(i)
    def userCall = row.getValue("f603")
    def node_00 = node_24.where("USER_CALL = '" + userCall + "'")
    node_00.to(hiveDs, "result_" + i).nodeId("n" + i)
}

// for-each：批量给多个节点下发计算逻辑
def areaCodes = ["320100", "320200", "320300", "320400"]
def centralHive = hive("/datasource/hive.properties").areaCode("320000")
for (String areaCode : areaCodes) {
    def hiveDs = hive("/datasource/hive.properties").areaCode(areaCode)
    from(hiveDs, "t_person")
        .where("id_card = '320323198809110214'")
        .select("name, id_card, age, '" + areaCode + "' as areaCode")
        .to(centralHive, "t_person_all")
}

// for-each：批量处理多张表
def tables = ["t_qq", "t_wx", "t_weibo"]
for (String table : tables) {
    def hiveDs = hive()
    from(hiveDs, table)
        .where("id_card = '320323198809110214'")
        .select("name, id_card, '" + table + "' as table_name")
        .to(hiveDs, "t_person_all")
}
```

## 系统内置变量

### VAR_TEMP_TABLE

每个数据集对象都有一个全局唯一的临时表名，任务执行完成后自动删除。`VAR_TEMP_TABLE` 和 `tempTable` 是等价属性。

```groovy
// 示例：用临时表名写自定义 SQL（前置数据集无需显式 to() 落库）
def df1 = from(hiveDs, "dw.source").select("id", "name").where("status != 0")
def df2 = query(hiveDs, "select * from ${df1.VAR_TEMP_TABLE}").depend(df1)
// 等价写法：${df1.tempTable}
def df3 = df2.to(hiveDs, "dw.result")
```

## 动态变量 variable()

通过内置变量生成器声明动态变量，运行时自动替换为实际值。

```groovy
// 语法
def vars = variable(varGeneratorName[, varParams])
// 引用方式：${vars.变量名}
```

### 1. 当前时间变量 CurrentTimeVar

```groovy
// 参数：timeVarName（变量名）、timeFormat（可选，不填输出绝对秒）
def timeVar = variable("CurrentTimeVar", [timeVarName: "today", timeFormat: "yyyy-MM-dd"])
from(hiveDs, "dw.t_order")
    .where("dt = '${timeVar.today}'")
    .to(hiveDs, "dw.t_order_result")

// 常用格式对照
// ${DATE8}   → variable("CurrentTimeVar", [timeVarName:"DATE8",  timeFormat:"yyyyMMdd"])
// ${DATE10}  → variable("CurrentTimeVar", [timeVarName:"DATE10", timeFormat:"yyyyMMddHH"])
// ${DATE14}  → variable("CurrentTimeVar", [timeVarName:"DATE14", timeFormat:"yyyyMMddHHMMss"])
// ${DATE_8}  → variable("CurrentTimeVar", [timeVarName:"DATE_8", timeFormat:"yyyy-MM-dd"])
// ${DATE_14} → variable("CurrentTimeVar", [timeVarName:"DATE_14", timeFormat:"yyyy-MM-dd HH:MM:ss"])
// ${SEC}     → variable("CurrentTimeVar", [timeVarName:"SEC"])   // 绝对秒
```

### 2. 通用增量抽取变量 CommonIncrementVar

自动生成增量 WHERE 条件片段：
- 首次抽取：`field <= currentMaxValue`
- 增量抽取：`lastMaxValue < field and field <= currentMaxValue`
- 无新数据：`LENGTH('gdl') = 3`
- 表无数据：`1=1`

```groovy
// 参数：tableName、queryFieldName、fieldAliasName（可选）
//       execMinPoint（可选，抽取范围开始值，支持 "select xx" 查询SQL）
//       execMaxPoint（可选，抽取范围结束值，支持 "select xx" 查询SQL）
def captureTimeVar = variable("CommonIncrementVar", [
    tableName     : "dw.t_order",
    queryFieldName: "create_time",
    fieldAliasName: "captureTime"
])
from(hiveDs, "dw.t_order")
    .select("area_code, create_time as captureTime, id")
    .where("area_code='320100' and ${captureTimeVar}")
    .to(hiveDs, "dw.t_order_inc")
```

## 分区变量

### BdosPartitionIncrementVar — 分区增量读取

```groovy
def partVars = variable("BdosPartitionIncrementVar", [
    tableName        : "dw.t_partition_table",
    partitionName    : "p3",
    stepLength       : 10,
    execMinPoint     : "1747418434",   // 可选，抽取范围开始值，支持 "select xx" 查询SQL
    execMaxPoint     : "1748368856",   // 可选，抽取范围结束值，支持 "select xx" 查询SQL
    partitionBeginVar: "p3Begin",
    partitionEndVar  : "p3End"
])
from(hiveDs, "dw.t_partition_table")
    .where("p1='final' and p3 > ${partVars.p3Begin} and p3 <= ${partVars.p3End}")
    .to(hiveDs, "dw.t_result")
```

### BdosPartitionModifyIncrementVar — 分区修改时间增量

按分区最后修改时间增量抽取，生成分区列表变量。

```groovy
def partListVars = variable("BdosPartitionModifyIncrementVar", [
    tableName       : "dw.t_partition_table",
    partitionName   : "p3",
    stepLength      : 10,
    partitionListVar: "partList"
])
from(hiveDs, "dw.t_partition_table")
    .where("p3 in (${partListVars.partList})")
    .to(hiveDs, "dw.t_result")
```

### BdosReadLastNPartitionVar — 最新 N 个分区

```groovy
def partVars = variable("BdosReadLastNPartitionVar", [
    tableName        : "dw.t_partition_table",
    partitionName    : "p3",
    stepLength       : 10,
    repeat           : true,       // 是否允许重复抽取
    partitionBeginVar: "p3Begin",
    partitionEndVar  : "p3End"
])
```

### BdosReadLastOnePartitionVar — 最新一个分区

```groovy
def lastVar = variable("BdosReadLastOnePartitionVar", [
    tableName    : "dw.t_partition_table",
    partitionName: "p3",
    partitionVar : "lastP3"
])
from(hiveDs, "dw.t_partition_table")
    .where("p3 = ${lastVar.lastP3}")
    .to(hiveDs, "dw.t_result")
```

### BdosReadLastPartitionVar — 读取到最新分区（Begin/End）

读取到最后一个分区，产生分区开始和分区结束两个变量值。支持 `execMinPoint`/`execMaxPoint` 指定范围。

```groovy
// 指定范围分区增量
def partVars = variable("BdosReadLastPartitionVar", [
    tableName        : "dw.t_partition_table",
    partitionName    : "p3",
    execMinPoint     : "1747418434",   // 可选
    execMaxPoint     : "1748368856",   // 可选
    partitionBeginVar: "p3Begin",
    partitionEndVar  : "p3End"
])
from(hiveDs, "dw.t_partition_table")
    .where("p3 > ${partVars.p3Begin} and p3 <= ${partVars.p3End}")
    .to(hiveDs, "dw.t_result")

// 不指定范围（全部分区增量）
def partVars = variable("BdosReadLastPartitionVar", [
    tableName        : "dw.t_partition_table",
    partitionName    : "p3",
    partitionBeginVar: "p3Begin",
    partitionEndVar  : "p3End"
])
```

## 脚本参数注入

通过任务提交接口的 `params` 参数注入，在 GDL 中直接以变量名引用：

```groovy
// params 中传入 key=areaCode, value=320100
if (320100 == areaCode) {
    // 使用节点编码分支逻辑
}

// 数据库账号密码注入（避免硬编码）
def pg = postgres("172.16.31.206", 15432, "mydb", "${pgUserName}", "${pgPassword}")
```

# 集合与关联算子

---

## 并集算子

### union() / unionAll()

| 方法 | 说明 |
|---|---|
| `union()` | 并集并去重 |
| `unionAll()` | 并集不去重 |

```groovy
def datasetA = from(hiveDs, "stg_per_base").select("id_no", "mobile")
def datasetB = from(hiveDs, "stg_mobile_base").select("id_no", "mobile")
def datasetC = datasetA.union(datasetB)
def datasetD = datasetA.unionAll(datasetB)
```

> **注意：** 两个数据集结构必须一致，如不一致需先用 select() 统一。

---

## 差集算子

### subtract() / subtractAll()

| 方法 | 说明 |
|---|---|
| `subtract()` | 差集并去重 |
| `subtractAll()` | 差集不去重 |

```groovy
def datasetC = datasetA.subtract(datasetB)               // 全字段差集
def datasetC = datasetA.subtract(datasetB, "id_no")      // 按指定字段差集
```

---

## 交集算子

### intersect() / intersectAll()

| 方法 | 说明 |
|---|---|
| `intersect()` | 交集并去重 |
| `intersectAll()` | 交集不去重 |

```groovy
def datasetC = datasetA.intersect(datasetB)              // 全字段交集
def datasetC = datasetA.intersect(datasetB, "id_no")     // 按指定字段交集
```

## 关联算子

### join() — 内关联

```groovy
def datasetC = datasetA.join(datasetB, "stg_per_base.id_no = stg_mobile_base.id_no")
```

### leftJoin() — 左关联

```groovy
def datasetC = datasetA.leftJoin(datasetB, "stg_per_base.id_no = stg_mobile_base.id_no")
```

### rightJoin() — 右关联

```groovy
def datasetC = datasetA.rightJoin(datasetB, "stg_per_base.id_no = stg_mobile_base.id_no")
```

### fullJoin() — 全关联

```groovy
def datasetC = datasetA.fullJoin(datasetB, "stg_per_base.id_no = stg_mobile_base.id_no")
```

## 存在性算子

### exists()

返回左表中在右表里存在匹配行的记录。

```groovy
def dataset = datasetA.exists(datasetB, "stg_per_base.id_no = stg_mobile_base.id_no")
```

### notExists()

返回左表中在右表里不存在匹配行的记录。

```groovy
def dataset = datasetA.notExists(datasetB, "stg_per_base.id_no = stg_mobile_base.id_no")
```

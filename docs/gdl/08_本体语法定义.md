# 本体语法定义（Ontology）

本体是 GDL 的业务领域模型，封装了业务属性和操作方法，基于 Groovy class 定义，运行在 TRE 引擎中。

---

## 使用流程

```
业务定义 GDL 本体 → 注册到 TRE → 应用使用本体
```

1. 定义本体（Groovy class 继承 Ontology 基类）
2. 注册到 TRE（SDK 接口 或 文件上传热加载）
3. 在 GDL 脚本中实例化本体对象，使用属性和方法

---

## Ontology 基类

所有业务本体必须继承 `Ontology` 基类。

### 基类属性

| 属性名 | 类型 | 是否必须 | 说明 |
|---|---|---|---|
| `oId` | String | 是 | 本体唯一标识，格式：`{业务代号}_{本体分类编码}_{本体编号}` |
| `oName` | String | 是 | 本体中文名称 |
| `oDesc` | String | 是 | 本体描述（属性、方法、使用场景等） |
| `oTable` | String | 否 | 对应物理表名，没有物理表可不赋值 |
| `oAuthor` | String | 是 | 作者工号 |
| `oDs` | CmdDatasource | 否 | 物理表所在数据源，应用方使用时初始化 |
| `oDataframe` | CmdDataframe | 否 | 本体数据集，由 `loadData()` 自动赋值 |

### 基类方法

| 方法 | 说明 |
|---|---|
| `loadData(outerData)` | 加载外部数据集入本体（可重写） |
| `loadData()` | 无参版，业务重写后可内置加载逻辑 |
| `genODataframe()` | 获取本体数据集（含属性字段映射） |
| `toOtherOntology(mapping, other)` | 将本体数据传递给另一个本体 |
| `depend(CmdDataframe... depends)` | 设置外部依赖数据集 |
| `areaCode(String... areaCode)` | 设置漂移节点 |
| `getQueryDataframe(String... areaCodes)` | 获取查询结果数据集 |
| `returnDf()` | 将查询结果集返回给调用客户端 |
| `save(Map record)` | 插入数据到本体物理表 |
| `delete(String expr)` | 按条件删除数据 |
| `update(String expr, Map record)` | 按条件更新数据 |
| `addColumns(String fields)` | 追加物理表字段 |
| `dropTable()` | 删除本体物理表 |

**查询链（类似数据集算子）：**

```
where() / select() / mapping() / sort() / limit() / distinct() / to() / nodeId()
```

## 业务本体开发规范

```groovy
package v1   // 版本号：v1、v2、v3...

@Table(type="ORC", remarks="微信群聊")  // 表注解
class Chat extends Ontology {

    // 属性值 = 物理表字段名
    @Column(dataTypeName="string", remarks="群标识")
    String groupId = "group_id"

    @Column(dataTypeName="string", remarks="微信标识")
    String wxId = "wx_id"

    @Column(dataTypeName="string", remarks="聊天内容")
    String content = "content"

    Chat() {
        // 必须初始化这些基类属性
        super.oId     = "TS_00001_00001"
        super.oName   = "群聊本体"
        super.oDesc   = "群聊本体包含属性：群组ID、微信ID、聊天内容"
        super.oTable  = "dw.t_chat"
        super.oAuthor = "X0001"
        super.oDs     = hive()  // 可在构造方法中设置默认数据源
    }

    // 内置加载逻辑（无参，开箱即用）
    CmdDataframe loadData() {
        def tChatInterface = from(oDs, "t_chat_interface")
        if (depends != null && depends.length > 0) {
            tChatInterface.depend(depends)
        }
        def prepData = tChatInterface.where("i_group_id = 100000")
            .mapping((groupId): "i_group_id", (wxId): "i_wx_id", (content): "i_content")
        super.loadData(prepData)
    }

    // 重写 loadData(outerData)（可选，合并外部数据）
    @Override
    CmdDataframe loadData(CmdDataframe outerData) {
        def innerData = from(oDs, "t_chat_interface2").where("i_group_id = 20000")
            .mapping((groupId): "i_group_id", (wxId): "i_wx_id", (content): "i_content")
        def result = innerData.union(outerData).distinct()
        super.loadData(result)
    }

    // 业务私有方法
    def filterKeywords(String keywords, String tableName) {
        def fromOntology = genODataframe()
        def result = fromOntology.where("content like '%${keywords}%'")
            .select("groupId, wxId, content")
        def A = result.to(oDs, tableName)
        super.queryDataframe = A
        return this
    }
}
```

## @Table 注解参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `remarks` | String | 表注释 |
| `type` | String | 表类型：ORC、FRC、MAGICTABLE（默认 ORC） |
| `readOnly` | boolean | 是否只读（默认 true，只读则无法修改物理表） |
| `properties` | 数组 | 表属性，如 `@KeyValue(key="table.ttl", value="8640000")` |

## @Column 注解参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `cName` | String | 列中文名 |
| `dataTypeName` | String | 数据类型（默认 String） |
| `remarks` | String | 列说明 |
| `dataLength` | int | 数据长度 |
| `decimalDigits` | int | 小数位 |
| `nullable` | boolean | 是否允许为空（默认 true） |
| `partition` | boolean | 是否分区字段（默认 false） |
| `primaryKey` | boolean | 是否主键（默认 false） |
| `originalColumnName` | String | 原始字段名（仅用于 FRC 分区字段） |
| `partitionRule` | String | 分区规则：yyyy/yyyyMM/yyyyMMdd（仅 FRC） |

## 本体 CRUD 操作

### save() — 插入

```groovy
v1.Chat chat = new v1.Chat(oDs: hiveDs)
chat.save([id: "1", name: "xiaoming", age: "12"])
```

### delete() — 删除

```groovy
v1.Chat chat = new v1.Chat(oDs: hiveDs)
chat.delete("id = 1")
```

### update() — 更新

```groovy
v1.Chat chat = new v1.Chat(oDs: hiveDs)
chat.update("id = 1", [name: "xiaoming", age: "12"])
```

### 查询操作（链式）

```groovy
v1.Chat chat = new v1.Chat(oDs: hiveDs)
chat.where("age > 0 and age < 150")
    .select("groupId, wxId, content")
    .sort("groupId desc")
    .limit(100)
    .distinct()
chat.returnDf()
```

## 本体使用示例

```groovy
def hiveDs = hive()
v1.Chat chat = new v1.Chat(oDs: hiveDs)

// 1. 使用默认 loadData 加载
chat.loadData()

// 2. 外部数据驱动加载
def outerData = from(hiveDs, "t_chat_interface")
    .where("i_group_id = 200")
    .mapping((chat.groupId): "i_group_id", (chat.wxId): "i_wx_id", (chat.content): "i_content")
chat.loadData(outerData)

// 3. 使用业务方法
chat.filterKeywords("毒品", "t_chat_result")

// 4. 与基础算子结合使用
def pDf = from(hiveDs, "t_chat_interface2").alias("a")
def oDf = chat.genODataframe().alias("b")
pDf.join(oDf, "a.i_wx_id = b.wxId").select("a.i_wx_id", "b.content").to(hiveDs, "t_result")

// 5. 本体间数据传递
v1.Chat2 chat2 = new v1.Chat2(oDs: hiveDs)
def mapping = [(chat2.groupId): chat.groupId, (chat2.wxId): chat.wxId, (chat2.content): chat.content]
chat.toOtherOntology(mapping, chat2)

// 6. 漂移查询（跨节点）
chat.areaCode("320100", "320200").where("id = 1")
def df = chat.getQueryDataframe()

// 7. 获取查询结果集并进一步分析
chat.areaCode("320100", "320200")
chat.where("id = 1")
def df = chat.getQueryDataframe()
def hiveRemote = hive().areaCode("320100")
df.where("name = 'xiao'").to(hiveRemote, "result_table")

// 8. 物理表结构操作
chat.addColumns("ip1 string, ip2 int comment 'ip地址'")
chat.dropTable()
```

## 本体注册管理

### SDK 接口注册

```java
// 注册单个本体
RegisterRsp treClient.registerOntology(String gdl)
// 批量注册（支持本体间依赖）
RegisterRsp treClient.registerOntologies(List<String> gdls)
// 批量更新（覆盖已注册本体）
RegisterRsp treClient.updateOntologies(List<String> gdls)
// 删除本体
RegisterRsp treClient.unregisterOntology(String names)  // 例："v1.Chat,v1.Http"
```

**RegisterRsp 返回：**

| 字段 | 类型 | 说明 |
|---|---|---|
| `status` | int | 0：失败，1：成功，2：部分成功 |
| `message` | String | 结果描述 |
| `data` | Map | 批量操作时返回各本体的结果 |

### 文件上传注册

1. 本体文件命名：`本体名称.gdl`（例：`Chat.gdl`）
2. 上传至热加载目录（由 `gdl.temp.file.path` 配置）
3. 引擎自动热加载

## 本体查询接口

### SDK 查询本体信息

```java
List<OntoInfoRsp> treClient.getOntologies(String fullOntologyNames)
// fullOntologyNames：指定本体完整名称，多个逗号分隔，传 null 查询全部
```

**OntoInfoRsp 返回字段：**

| 字段 | 类型 | 说明 |
|---|---|---|
| `oId` | String | 本体ID |
| `oName` | String | 本体名称 |
| `oDesc` | String | 本体描述 |
| `oTable` | String | 本体物理表名 |
| `version` | String | 版本（对应 package） |
| `className` | String | 本体类名称 |
| `fields` | List | 本体属性列表（fieldName、columnName、dataTypeName、remarks） |
| `methods` | List | 本体方法列表（methodName、returnType、params） |

### SDK 获取查询结果

```java
TaskResult treClient.getTaskResult(String taskId)
```

**TaskResult 返回：** status（任务状态）、result 列表（每个地市的 areaCode、code、data、metadata）。

### HTTP 接口

```
GET http://[IP]:[PORT]/tre/api/getOntologies?fullOntologyNames=v1.Chat&areaCode=320100
Header: tre-token=xxxx
```

### MCP 接口

TRE 提供 MCP 工具方法：

| 工具方法 | 说明 |
|---|---|
| `start_task` | 下发 GDL 脚本执行（code 参数为脚本内容） |
| `get_task_result` | 根据 taskId 获取执行结果 |
| `get_tsml_to_dag` | 将 GDL 脚本转为 DAG 图（点线边 JSON）（方法名为 TRE 历史接口名） |

MCP 服务地址：`http://[IP]:[PORT]/tre/mcp/service`（streamableHttp 类型）

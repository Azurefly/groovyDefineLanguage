# 数据源定义

GDL 支持多种数据源，所有数据源均返回 `CmdDatasource` 对象，并支持链式调用 `.areaCode()` 设置漂移节点。

---

## hive() / hivehw()

Hive 数据源（基于华为 Hive 3.1.x）。

```groovy
// 语法
def 数据源 = hive(["dsConfName"])[.areaCode("节点编码")]

// 示例
def hiveDs  = hive()                     // 使用默认配置
def hiveDs  = hive("dsConfName")         // 指定配置目录
def hiveDs  = hive("/home/xxx/conf")     // 指定绝对路径
def hiveNJ  = hive().areaCode("320100") // 标记为南京节点
```

> 底层函数名为 `hivehw()`，`hive()` 为其别名，二者等价。

---

## postgres()

PostgreSQL 数据源。

```groovy
// 语法
def 数据源 = postgres(host, port, database, username, password)[.areaCode("节点编码")]

// 示例
def pg      = postgres("172.16.31.206", 15432, "mydb", "${pgUser}", "${pgPassword}")
def pgDrift = postgres("172.16.31.206", 15432, "mydb", "${pgUser}", "${pgPassword}").areaCode("320100")
```

---

## llm()

大模型数据源（LLM API 调用）。

```groovy
// 语法
def llmDs = llm(url, concurrent)[.areaCode("节点编码")]

// 示例
def llmDs       = llm("http://172.17.62.1:28000/v1/chat/completions", 10)
def defaultLlmDs = llm()                           // 使用配置文件中的默认 LLM 配置
def remoteLlmDs  = llm().areaCode("320100")        // 使用远端节点的大模型

// 配置文件参数（tre.properties）
// tre.llm.url=http://...
// tre.llm.concurrent=10
// tre.llm.response.timeout=1800
```

---

## areaCode()（漂移标记）

所有数据源均支持 `.areaCode()` 方法，引擎据此切割本地/远端执行子图。

```groovy
def hiveRemote = hive("hive-conf").areaCode("320100")  // 标记为远端节点数据源
```

# 实时算子（流计算场景）

实时算子用于流计算场景，字段**大小写敏感**。

---

## 窗口算子

窗口算子必须紧跟 `.group()` 使用，分组字段只能为 `window_start` 和 `window_end`。

时间单位：`SECONDS` | `MINUTES` | `HOURS` | `DAYS`

---

### tumbleWindow() — 滚动窗口

固定大小、不重叠的时间窗口。每个元素归属于唯一一个窗口。

```groovy
// 语法
def 数据集 = 数据集.tumbleWindow("时间字段", "窗口大小", "时间单位"[, "偏移量", "偏移单位"])
    .group("window_start, window_end", "聚合表达式")

// 示例：每 10 分钟统计一次销售额
def result = dataset.tumbleWindow("event_time", "10", "MINUTES")
    .group("window_start, window_end", "sum(price) as total")

// 带偏移量（窗口向前偏移 5 分钟）
def result = dataset.tumbleWindow("event_time", "10", "MINUTES", "5", "MINUTES")
    .group("window_start, window_end", "sum(price) as total")
```

---

### hopWindow() — 滑动窗口

固定大小、可重叠的时间窗口，由滑动步长控制窗口开始频率。

```groovy
// 语法
def 数据集 = 数据集.hopWindow("时间字段", "滑动时间", "滑动单位", "窗口大小", "窗口单位"[, "偏移量", "偏移单位"])
    .group("window_start, window_end", "聚合表达式")

// 示例：每 5 分钟开始一个 10 分钟的窗口
def result = dataset.hopWindow("event_time", "5", "MINUTES", "10", "MINUTES")
    .group("window_start, window_end", "sum(price) as total")
```

---

### cumulateWindow() — 累积窗口

窗口随时间逐步扩展，每个步长增加一个窗口大小，直到达到最大窗口。

> **限制：** 窗口大小必须是步长的整数倍。

```groovy
// 语法
def 数据集 = 数据集.cumulateWindow("时间字段", "步长时间", "步长单位", "窗口大小", "窗口单位"[, "偏移量", "偏移单位"])
    .group("window_start, window_end", "聚合表达式")

// 示例：每 2 分钟累积一次，10 分钟输出全量结果
def result = dataset.cumulateWindow("event_time", "2", "MINUTES", "10", "MINUTES")
    .group("window_start, window_end", "sum(price) as total")
```

## 信号量算子（控制调度时机）

### periodReactor() — 周期性信号

按 Cron 表达式周期性触发后续计算。

```groovy
// 场景1：接在某个节点之后，等该节点完成后再周期触发
def 数据集2 = 数据集.periodReactor("cron表达式")

// 场景2：全局周期调度（不依赖任何前置节点）
def df = periodReactor("cron表达式")

// 示例：每 3 分钟触发一次
def df2 = df1.periodReactor("0 0/3 * * * ?")
def df3 = df2.select("id, area_code").to(hiveDs, "result_table")

// 示例：全局每天凌晨 1 点执行
def trigger = periodReactor("0 0 1 * * ?")
def dataset = from(hiveDs, "dw.source_table").depend(trigger)
```

---

### taskReactor() — 任务驱动信号

等待指定前置任务达到成功率，满足条件后触发。

```groovy
// 语法
def 数据集 = taskReactor(["任务ID1", "任务ID2"], 成功完成百分比, 延迟时间秒)

// 示例：60% 任务成功后立即执行，或有一个成功后延迟 30s 执行
def df = taskReactor(
    ["168BEAB1C5A5609C3D5713BA3C40B8C7", "6469EFA281729D42EC2A1C27A768F627"],
    60,
    30
)
```

---

### increment() — 增量信号

周期性查询 SQL，当结果集达到命中条数或等待超时，触发后续计算。

```groovy
// 语法
def 数据集2 = 数据集.increment(数据源, 查询SQL, 增量字段名, 命中条数, 最大等待时间秒)

// 示例
def trigger = periodReactor("0 0/1 0-23 * * ? *")
def df = trigger.increment(
    hiveDs,
    "select id, capture_time from stg_per_base where age > 60",
    "capture_time",
    100,    // 命中 100 条触发
    300     // 最长等待 300 秒
)
// 从增量信号产生的临时表继续处理
def df1 = from(hiveDs, "${df.VAR_TEMP_TABLE}").depend(df).alias("a")
def df2 = df1.to(hiveDs, "stg_result")
```

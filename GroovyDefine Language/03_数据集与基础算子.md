# 数据集与基础算子

数据集 `CmdDataframe` 是 GDL 的核心数据结构，所有算子均以数据集为输入，返回新的数据集（链式调用）。

---

## from() — 数据集定义

从数据源读取一张表，创建数据集。

```groovy
// 语法
def 数据集 = from(数据源, "[库名.]表名")[.alias("别名")][.depend(dataset1[, dataset2])]

// 示例
def dataset = from(hiveDs, "t_person")
def dataset = from(hiveDs, "t_person").alias("a")
def dataset = from(hiveDs, "dw.t_person")             // 带库名

// 带依赖（先等待前置步骤完成再查询）
def df0 = insert(pgDs, "public.t_person", "insert into t_person(insert_date) values('2025-04-03')")
def dataset = from(pgDs, "public.t_person").depend(df0)
```

---

## nodeId() — 节点ID

与应用层画布节点对应，同一画布内 nodeId 必须唯一。

```groovy
def filteredDf = a.select("xuhao").where("xuhao != '123'").nodeId("提取-0001")
```

---

## where() — 行过滤

按条件过滤行，遵循 SQL WHERE 语法。

```groovy
def filteredDataset = dataset.where("age > 0 and age < 150")
def result = dataset.where("name like '%张%' and status = 1")
```

---

## select() — 列过滤

选取/转换列，支持函数和别名。

```groovy
def dataset = dataset.select("age", "name as person_name", "replace(email,'@old.com','@new.com') as email")
```

---

## mapping() — 字段映射

以 Map 形式表达别名和源字段的映射关系。

```groovy
def dataset = dataset.mapping(
    age        : "age",
    person_name: "name",
    email      : "replace(email,'@old.com','@new.com')"
)
```

---

## withColumn() — 列计算/扩展

修改某列或新增一列。

```groovy
def dataset = dataset.withColumn("mobile", "concat('+86', mobile)")
def dataset = dataset.withColumn("birthday", "substring(idCard, 6, 13)")
def newdf   = df.withColumn("age", "split(column,'[\\t;,]',2)[0]", "String")  // 带类型
```

---

## group() — 分组聚合

```groovy
def datasetA = dataset.group("sex", "count(sex) as count_sex")
def datasetB = dataset.group("sex", "count(sex) as count_sex").where("count_sex > 10")  // having 用 where 代替
def datasetC = dataset.group("class,sex", "avg(age) as ave_age")
// 行合并
def datasetD = dataset.group("idNo,name,age", "concat_ws('###', sort_array(collect_list(mobile))) as mobile")
```

---

## sort() — 排序

```groovy
def dataset = dataset.sort("id_no desc", "age asc")
def dataset = dataset.sort("id_no desc", "age asc").index("rowNum")  // 附加序号列
```

---

## distributeSort() — 分区排序

先按分区字段分区，再在各分区内排序。

```groovy
def dataset = dataset.distributeSort("id_no, name", "age")
```

---

## limit() — 分页/限行

```groovy
def datasetA = dataset.limit(1000)      // top 1000
def datasetB = dataset.limit(0, 50)    // 第 1 页 50 条
def datasetC = dataset.limit(50, 50)   // 第 2 页 50 条
```

---

## distinct() — 去重

```groovy
def datasetA = dataset.distinct()                   // 全字段去重
def datasetB = dataset.distinct("id_no", "name")   // 指定字段去重
```

---

## groupSortFirst() — 分组排序取第一条

```groovy
def dataset = dataset.groupSortFirst("id_no, name", "age desc")
```

---

## alias() — 别名

```groovy
def dataset = from(hiveDs, "t_person").alias("a")
def result  = a.select("a.age, a.name").where("a.name != '张三'")
```

---

## comment() — 注释算子

记录脚本设计思路，引擎收集这些注释与 GDL 的对应关系。

```groovy
comment("""模型构建思路：
  第一步提取基础数据，第二步过滤异常记录，第三步聚合输出。
""")
```

# 漂移算子（跨节点计算）

漂移计算对 GDL 使用方透明。引擎根据数据源的 `areaCode` 将算子图切割为**本地执行子图**和**远端执行子图**，分别下发执行。

---

## 核心概念

- **areaCode**：标记数据源/本体/http 等所属节点，是漂移判断的依据
- **本地算子**：无 areaCode 或 areaCode = 本地节点的算子，在当前引擎节点执行
- **远端算子**：带有远端 areaCode 的算子，被切割下发至目标引擎节点执行
- **中间表**：跨节点的数据通过临时中间表传输（FRC 格式），任务完成后自动清理

---

## areaCode() — 数据源漂移标记

```groovy
// 标记数据源为 320100 节点
def hiveNJ    = hive("hive-conf").areaCode("320100")
def pgRemote  = postgres("host", 5432, "db", "user", "pwd").areaCode("320100")
def llmRemote = llm().areaCode("320100")
```

## 漂移脚本示例

**原始 GDL（用户编写）：**

```groovy
def hiveRemote = hive("hive-conf").areaCode("320100")
def hiveLocal  = hive("hive-local")

// 从远端读取数据
def node_1 = from(hiveRemote, "dw.t_user").alias("node_1")
def node_2 = node_1.where("node_1.update_time <= 1731293680")
    .select("node_1.user_id as f1, node_1.mobile as f2")

// 写入本地
node_2.to(hiveLocal, "dw.t_result").nodeId("3")
```

**引擎切割后 — 远端执行 GDL：**

```groovy
def hiveDs = hive("hive-conf")
def df = from(hiveDs, "dw.t_user").alias("node_1")
    .where("node_1.update_time <= 1731293680")
    .select("node_1.user_id as f1, node_1.mobile as f2")
// 漂移发送数据到本地节点
def driftToDf = driftTo("local_node").attach(df, "", "tre_temp_xxx", "frc")
```

**引擎切割后 — 本地执行 GDL：**

```groovy
def hiveLocal = hive("hive-local")
def df = driftFrom(hiveLocal, "tre_temp_xxx", "frc").alias("node_1")
df.to(hiveLocal, "dw.t_result").nodeId("3")
```

---

## driftTo() — 漂移发送

向目标节点发送数据（一般由引擎自动生成，不需手写）。

```groovy
// 语法
def 漂移数据源 = driftTo("areaCode")
    .attach(数据集1, "原始表名", "新表名", "类型")  // 类型：table | bit | frc
    [.attach(数据集2, "原始表名", "新表名", "类型")]

// 示例
def ds = driftTo("320100")
    .attach(df1, "t_person1", "temp_t_person1", "table")
    .attach(df2, "t_person2", "temp_t_person2", "frc")
```

---

## driftFrom() — 漂移接收

从漂移中间表中加载数据集（一般由引擎自动生成，不需手写）。

```groovy
// 语法
def 数据集 = driftFrom(数据源, "数据集名称", "类型")

// 示例
def df = driftFrom(hiveLocal, "temp_t_person1", "frc")
```

## 漂移场景完整示例

### 批量漂移（for 循环）

```groovy
def areaCodes = ["320100", "320200", "320300", "320400"]
def centralHive = hive("/datasource/hive.properties").areaCode("320000")

for (String areaCode : areaCodes) {
    def hiveDs = hive("/datasource/hive.properties").areaCode(areaCode)
    from(hiveDs, "t_person")
        .where("id_card = '320323198809110214'")
        .select("name, id_card, age, '" + areaCode + "' as areaCode")
        .to(centralHive, "t_person_all")
}
```

### HTTP 算子漂移（调用远端 HTTP 服务）

```groovy
def hiveLocal  = hive()
def hiveRemote = hive("hive-conf").areaCode("441200")

// 本地查询数据
def df = from(hiveLocal, "dw.t_base").where("type = 1")

// 调用远端 HTTP 服务
def df2 = df.http("GET", "http://10.0.9.173:8083/api/query").areaCode("441200")
    .form("taskId": "REF{ename}")
    .response("/data", true, [["fieldName": "taskId", "fieldPath": "/taskId", "dataType": "VARCHAR", "dataLength": 50]])
    .to(hiveRemote, "dw.t_http_result_remote")

// 将远端结果拉回本地
df2.to(hiveLocal, "dw.t_http_result_local")
```

### groovy 算子漂移

```groovy
def hiveLocal  = hive()
def hiveRemote = hive("hive-conf").areaCode("441200")

// 在远端执行 groovy 脚本
def df1 = from(hiveRemote, "dw.stg_per_base").where("name = '李四'")
def df2 = df1.groovy({ dataFrame -> {
    dataFrame.forEach { row -> {
        String idno = row.getValue("id_no")
        row.setValue("name", idno + ":" + row.getValue("name"))
    }}
    return dataFrame
}}).to(hiveRemote, "dw.t_result_remote")

// 将远端处理结果拉回本地
df2.select("id_no, name").to(hiveLocal, "dw.t_result_local").overwrite()
```

## 漂移注意事项

1. **漂移地市标记**：通过 `areaCode()` 方法标记，不设置则默认为本地数据源
2. **中间表自动清理**：漂移使用的临时中间表（`tre_temp_xxx`）在任务完成后自动清理
3. **本体漂移**：本体对象也支持 `areaCode()` 方法，设置后方法调用自动漂移到目标节点执行
4. **引擎透明**：用户只需标记 areaCode，引擎自动切割并生成 driftTo/driftFrom 逻辑
